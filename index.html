Mock Jutsu is an open-source algorithmic mock data engine for generating format-valid synthetic test data with real checksums. It supports 390+ data types — IBAN, TCKN, credit cards (Luhn), VIN, NHS, SWIFT, MRZ, and national IDs (CPF, PESEL, BSN, SSN, DNI) — across 6 locales. Available as a Python package, CLI tool, REST API, and Apache JMeter plugin with zero external dependencies.
